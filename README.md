# Diagnostic Accuracy of Serum Cystatin C for Pediatric AKI
A Bayesian and Frequentist Diagnostic Test Accuracy Meta-Analysis

## Overview
This repository contains the full reproducible R code for a diagnostic
accuracy meta-analysis evaluating serum cystatin C for early detection
of acute kidney injury (AKI) in pediatric populations.

## Methods
- Bivariate random-effects meta-analysis (Reitsma model)
- Bayesian HSROC modeling with PC priors
- Meta-regression using Bayesian hierarchical models
- Predictive value estimation across prevalence scenarios
- Publication bias assessment using Deeks' funnel plot

## Key Results
- Pooled sensitivity: 78.2% (95% CI 72.6–82.9)
- Pooled specificity: 79.5% (95% CI 73.5–84.5)
- AUC: 0.854
- Clinical setting identified as a significant moderator
